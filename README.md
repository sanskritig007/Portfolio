## 🚀 Overview

Personal 3D portfolio and interactive web experience for **Sanskriti Goswami** — Full Stack Developer & Electronics & Communication Engineering undergraduate at Ajay Kumar Garg Engineering College (2023–2027), and Open Source Contributor at **GSSoC 2025**.

### 🌟 Core Experience & Features:
- **Interactive 3D WebGL Atmosphere**: Real-time procedural 3D displacement sphere with custom GLSL shaders, mouse-driven spring physics, and dynamic lighting.
- **Cyberpunk Decoder Typography**: Matrix-style alphanumeric typing and deciphering animations with spring physics.
- **Interactive 3D Device Showcases**: High-fidelity 3D glTF MacBook models with realistic texture projections, smooth parallax scrolling, and responsive viewport sizing.
- **Custom SG Luxury Monogram**: Precision geometric brand mark with smooth cyan hover sweep animation.
- **Direct Contact Experience**: Interactive inbox card with one-click email copying and contact communication channels.

## 💻 Getting Started Locally

### Prerequisites
- Node.js `18.0.0` or higher (recommended: Node 20+)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone git@github.com:sanskritig007/Portfolio.git

# Navigate to project directory
cd Portfolio

# Install dependencies
npm install
```

### Development Server

```bash
npm run dev
```
Open `http://localhost:7777` in your browser.

### Production Build

```bash
npm run build
```

## 🚢 Deployment on Vercel

This repository is pre-configured for instant deployment on **Vercel**:

1. Push code to your GitHub repository: `https://github.com/sanskritig007/Portfolio`
2. Connect repository in [Vercel Dashboard](https://vercel.com/new).
3. Framework Preset: **Remix** / **Vite**.
4. Click **Deploy**.
