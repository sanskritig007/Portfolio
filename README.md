## 🚀 Overview

This is the personal 3D developer portfolio of **Sanskriti Goswami**, an Electronics & Communication Engineering undergraduate at Ajay Kumar Garg Engineering College (2023–2027) and Open Source Contributor at **GSSoC 2025**.

### Key Features:
- **Interactive 3D WebGL Background**: Procedural organic 3D displacement sphere built with custom GLSL shaders and fluid spring physics.
- **Cyberpunk Decoder Text**: Dynamic glyph-scrambling typing animations.
- **3D Device Showcases**: High-fidelity 3D glTF MacBook and device models with real-time parallax physics.
- **Featured Projects**:
  - **[Stayria](https://stayria.onrender.com)**: Airbnb-inspired travel platform with real-time Mapbox geospatial visualization, Cloudinary media optimization, and hybrid MongoDB & MySQL architecture.
  - **[AI Code Reviewer](https://github.com/sanskritig007/AI-reviewer)**: AI-driven GitHub PR review engine with FastAPI BackgroundTasks, Pydantic validation, and SQLite commit deduplication.
- **Interactive Contact**: Direct inbox with 1-click email copy and message submission.

## 🛠️ Tech Stack

- **Framework**: [Remix](https://remix.run/) + [Vite](https://vitejs.dev/)
- **3D Graphics & WebGL**: [Three.js](https://threejs.org/) + GLSL Shaders
- **Animations & Transitions**: [Framer Motion](https://www.framer.com/motion/)
- **Styling**: Vanilla CSS Modules with custom design tokens
- **Hosting / Deployment**: [Vercel](https://vercel.com/) / Cloudflare Pages

## 💻 Getting Started Locally

### Prerequisites
Make sure you have Node.js `19.9.0` or higher installed.

### Installation

```bash
# Clone the repository
git clone git@github.com:sanskritig007/Portfolio.git

# Navigate to project directory
cd Portfolio

# Install dependencies
npm install
```

### Run Locally

```bash
npm run dev
```

Open your browser and navigate to `http://localhost:7777`.

### Build for Production

```bash
npm run build
```
